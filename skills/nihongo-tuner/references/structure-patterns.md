# 組み立ての型（結論先行とグループ化）

表面の癖を消しても、「前置き → 状況 → 理由 → 最後に結論」の順で書かれた段落は説明調に聞こえる。業務文書・技術文書・メールは、読み手が次にすることを最初に書き、情報の種類ごとに分けて並べる。記事は導入の段落で結論を示せばよい。エッセイにはこの型を当てない（`genres.md`）。

出典: ダンク「わかりやすい文章構成のコツ」（https://dank.jp/blog/sentence-structure/ ・2026-09-27参照）。要点は次の2つ。

- **グループ化**：条件・期間・金額・お願いなどが1段落に混ざっていたら、情報の種類ごとに分けてラベルを付ける。行動が人によって変わるなら、対象者ごとに分ける。
- **結論先行**：PREP（結論 → 理由 → 具体例 → 結論）を基本にするが、内容に合わせて並べ替える。例は結論 → 理由 → 補足、結論 → お詫び → 理由。「結論を最初に書く」だけは崩さない。

同じ記事は太字と蛍光ペンの強調を多く使っているが、その強調の仕方はここでは取り入れない（`surface-patterns.md` §1）。

## 文書の種類ごとの型

### 注意書き

**やってはいけないこと → 理由 → 例外**

修正前:

> 集計表は、各シートの1行目の見出しを目印にして列を探します。目印は `売上` シートの「伝票番号」、`入金` シートの「入金日」…です。`売上`・`入金` では、この文言を変えたり消したりすると、集計が「見出しが見つかりません」というエラーで止まります。`経費` はエラーが出ず、その列が集計から黙って消えるだけなので特に注意してください。

修正後:

> 見出しの文言は変えないでください。集計表は、各シートの1行目の見出しを目印にして列を探しています。
>
> - 目印の見出し：`売上` シートの「伝票番号」、`入金` シートの「入金日」…
> - 変えたときに起きること：`売上` と `入金` では、集計が「見出しが見つかりません」というエラーで止まります。`経費` ではエラーが出ないまま、その列が集計に含まれなくなります。

### 手順

**何をするか → 手順 → 補足**

「〜のときは」「〜するために」で始まる前置きの段落を、手順の前に置かない。目的は見出しか最初の一文で済ませる。手順が3つ以上あれば番号付きの箇条書きにする。

### 仕様の説明

**何が起きるか（何であるか） → 条件 → 例外**

修正前:

> 問い合わせには2つの経路があります。Webフォームから送信されたものと、メールの記入テンプレートで届いたものです。どちらの経路でも入る先は同じ問い合わせ一覧で、…記録されます。そのため、受付項目を変えたときはWebフォームとメールの記入テンプレートの両方を更新しないと、経路によって聞ける項目が食い違います。

修正後:

> 受付項目を変えたときは、Webフォームとメールの記入テンプレートの両方を更新してください。問い合わせは、Webフォームから送信する経路と、メールで届く経路のどちらからも、同じ問い合わせ一覧に入ります。「受付経路」列には `フォーム` か `メール` が記録されます。片方だけ更新すると、経路によって聞ける項目が食い違います。

### 対象者で行動が変わる説明

「〜の担当者は」「〜の場合は」で見出しか行頭のラベル（太字にしない）を立て、対象者ごとに分ける。1段落の中で「〜の場合は A、〜の場合は B」と続けない。

## グループ化の目安

- 1段落に、場所・条件・結果・例外のうち3つ以上が入っていたら分ける。
- ラベルは「編集する場所」「書き方」「変更後に必要な操作」「注意」のように、読み手の行動に対応させる。既に表の形になっている節はその表の項目名に合わせる。
- 分けた結果が2項目以下なら、箇条書きにせず2文に分けるだけでよい

## 組み立てを直さないもの

- 表・コードブロック・画面文言の引用
- 既に「結論 → 理由」の順になっている段落
- 用語集や一覧表のように、項目を並べること自体が目的の節

## 直しすぎない

同じ直し方を全部の節に当てると、元の文書にあった節ごとのばらつきがなくなり、かえって型にはめた文書に見える。natural-japanese（coji・MIT）の評価でも、見出しをすべて結論の文に変えた改稿は、内容の伝わりやすさでは元の文書を上回った一方で、人の書いた文書らしさでは下回っていた。

- 組み立てを直す前に、見出しと節の一覧を作り、節ごとに「そのまま」か「直す」かを決める。迷ったら「そのまま」にする。直す節が全体の3割を超えたら、報告に理由を書く。
- 見出しを結論の文にするのは、見出しだけでは中身の見当がつかず、探すのに手間取る節の2〜3か所に限る。すべての見出しを同じ形（「名詞：結論」など）にそろえない。
- 同じ形の定義文、同じ順序の節、同じ書き出しが3回続いたら、そのうち1か所以上で語順や主語を変える。型を崩す目的だけで、問いかけの文や体言止めを足さない。
- あとで特定の項目を引くための箇条書き（宿題や確認事項の一覧など）は、地の文に書き直さない。
